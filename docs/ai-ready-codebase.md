# AI-Ready Codebase Notes

AI-ready codebase는 AI를 위한 지도가 그려져 있는 코드베이스를 의미한다. 대규모 코드베이스에서는 AI가 전체 맥락을 한 번에 읽기 어렵고, 암묵적 규칙이나 과거 실패 사례를 알 수 없기 때문에 신입 개발자 온보딩 문서처럼 AI용 방향과 지침을 코드베이스 안에 둔다.

## 적용 원칙

- 루트 문서는 길게 쓰지 않고, 어디를 봐야 하는지 안내하는 인덱스 역할을 한다.
- 코드와 파일 구조를 읽으면 알 수 있는 사실은 `AGENTS.md`에 반복하지 않는다.
- AI가 잘못 추론하기 쉬운 금지선, 운영 원칙, 의사결정 이유만 짧게 남긴다.
- 폴더별 `AGENTS.md`는 반복 실수가 실제로 생긴 뒤에만 추가한다.
- 문서가 코드와 달라져 썩지 않도록, 큰 구조 변경 뒤에는 `docs/decisions.md`와 작성 가이드를 갱신한다.

## Context Hygiene

- 한 세션에는 하나의 작업만 다룬다.
- 설명은 요청받았을 때만 길게 한다.
- 모호한 요청은 전체 repo를 헤매기 전에 관련 파일과 성공 기준을 먼저 좁힌다.
- 긴 탐색은 별도 세션이나 하위 작업으로 분리하고, 메인 세션에는 요약만 가져온다.
- 시스템 프롬프트나 `AGENTS.md`는 자주 고치지 않는다. 전역 지시문 변경은 캐시와 행동 안정성을 흔든다.
