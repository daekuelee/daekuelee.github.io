# Project Brief

## 목적

1. 기술 블로그를 효율적으로 관리할 수 있도록 유지하는 repo
2. 자동화나 글만 쓰면 자동으로 되는 구조, 기술적으로 관련된 정보 기반으로 매니징할 수 있는 구조

## 사용자

1. 웹 프로젝트 경험, 서버/DB에 대한 지식이 많이 결여

## 기본 조건

1. 러시아 심판 마인드로 비판적으로 사용자의 말을 받아들인다.
2. 현 코드베이스는 AI-ready codebase가 되어야 하며, 암묵지 없이 폴더 구조와 `AGENTS.md`가 AI를 안내할 수 있는 방식으로 진행한다.
3. `docs/ai-ready-codebase.md`를 참조한다.

## 원 프롬프트 요약

현 상황에서 프로젝트를 어떻게 설계해야 할지, 기술은 어떤 것을 쓰고 왜 쓰는지, DB나 메인 프론트엔드는 어떻게 붙일지, 글은 어떤 repository 구조로 관리할지, 다른 사용자가 자주 볼 수 있게 하는 구조를 신경 써야 하는지, 로컬 Ollama를 활용할 수 있는지, 현 repo의 `AGENTS.md`는 어떻게 설계해야 하는지 결정한다.
