# Blog

Astro + MDX technical blog, learning notes, and developer showcase.

## Commands

- `npm run dev` - start local development
- `npm run check` - run Astro and content schema checks
- `npm run build` - build the static site and Pagefind index
- `npm run preview` - preview the production build
- `npm run new:post -- --title "Title" --lang ko --kind post` - create a draft MDX entry

## Content

- `src/content/posts` - polished technical articles
- `src/content/notes` - learning notes and experiments
- `src/content/projects` - project showcase pages

The public site is configured as the root GitHub Pages site.
